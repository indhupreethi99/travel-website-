# Travel Guide Website 🌍✈️

A modern and responsive Travel Guide Website built using HTML and CSS. This project showcases beautiful travel destinations, luxury hotels, restaurants, and fun activities with an attractive user interface and smooth responsive design.

## Features 🚀

- Responsive Navigation Bar
- Hero Section with Search Box
- Popular Destinations Section
- Hotel Booking Cards
- Restaurant Showcase
- Fun Activities Section
- Stylish Footer with Social Icons
- Hover Effects & Animations
- Fully Responsive for Mobile & Desktop
- Real High-Quality Images using Unsplash

## Technologies Used 💻

- HTML5
- CSS3
- Font Awesome Icons
- Google Fonts

## Project Purpose 🎯

This project was created to practice front-end web development skills and design a modern travel-themed landing page with responsive layouts and clean UI design.
